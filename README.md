# 坡道标注核查平台

坡道影像标注质检员的内部工具，提供两项核查能力：

1. **派单核查**：按标注员维护派单，自动产出三类问题清单——
   - **漏判**：派到但没有任何标注；
   - **重拍**：派到且标为「看不清」；
   - **错交**：没派到却有标注。
2. **两人一致性核查**：任选两位标注员，计算四种配对计数与 Cohen's κ，
   并可下载分歧清单。

## 启动

```bash
docker compose up --build
```

访问 http://localhost:8000 。SQLite 数据保存在名为 `qcdata` 的卷中。

本地开发（Python 3.11+）：

```bash
pip install -r requirements.txt
python app.py
```

## CSV 格式

### 标注 CSV（补传/更正）

UTF-8 编码，每行 `图号,标记`，首行可为表头：

```csv
图号,标记
1,有坡道
2,无坡道
3,看不清
```

- 图号：1～60000 的整数；标记：`有坡道` / `无坡道` / `看不清`。
- 同一 CSV 内同图多次出现时，以最后一行为准；同人同图重复上传视为更正。

### 派单 CSV（每行一个图号，整份替换）

```csv
图号
1
2
3
```

- 每行一个图号（1～60000），首行可为表头，同号自动去重。
- 上传即**整份替换**该标注员原派单，并带派单版本号。

## 派单核查规则

- **首次派单**：对该人全量核查，旧库里已有的标注直接参与。
- **换单（再次上传派单）**：只对新增、移除的图号重新核验，
  其余结果不重算、时间戳不变；派单表同样只做差量写入。
- **补传标注**：只 upsert 本批图号的原始标注，2bit 汇总就地打补丁
  （不回读整份原始标注），核查结果也只重新核验本批图号。
  派到的图补上标注即从漏判移除，标「看不清」进入重拍；
  派单外的图有标注即为错交。
- **物化结果**：三类结果存在 `qc_results` 表并带
  `(annotator, category, image_no)` 覆盖索引。查看一页只做索引区间扫描，
  不读原始标注、不遍历整份派单；每类图号升序，每页最多 50 个。
- **一致性**：新派单/更正与核查结果在同一事务中生效，任一步失败整体回滚，
  沿用原派单与原结果；数据库开启 WAL，上传期间仍可查；
  一次查看的三类总数与当页图号取自同一已提交快照（单读事务）。

## 两人一致性核查

- 原始标注存 SQLite；每人维护一份 2 bit/图 的压缩汇总
  （固定 15000 字节，上限 128 KiB），原始标注与汇总在同一事务中生效。
- 仅双方都判读为「有坡道/无坡道」的图参与配对（「看不清」与未标注不计入），
  输出四格计数与 Cohen's κ；没有有效配对或 κ 分母为零时提示无法比较。
- 核查只读汇总；分歧清单 CSV 下载带汇总版本号校验，数据已更新时返回 409
  需重新核查。
